## Reflection

I love working on small tasks like this on freeCodeCamp, but this is even more challenging because its not step-by-step, I have to figure out the steps myself. 

For this project I set up version control very simple, I like to work with a task in one sitting, and when im done i just make a commit. For bigger projects it is of course better to strategically commit changes.

I did not use automated tests for the tasks ive chosen, when the scope is this small I prefer to check my code by hand in the terminal.

And I just realized I did bad at documentation! I will improve on that, make a little note for each task and push the changes :)
